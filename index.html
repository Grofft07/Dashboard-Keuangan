Saldo Awal Bulanan

Patokan saldo di awal tiap bulan, untuk agensi dan akun iklan. Tanpa patokan, saldo awal dihitung otomatis dari seluruh riwayat transaksi (mulai dari 0).

Isi Patokan Saldo Awal

Kosongkan kolom patokan untuk memakai hitungan otomatis.
Nominal boleh singkat: 500rb, 2,5jt. Saldo minus boleh: tulis -500rb atau (500rb). Enter = baris berikutnya.
Mengunci saldo awal bulan itu = hasil hitung sampai akhir bulan sebelumnya. Patokan yang sudah ada tidak ditimpa.

Pengaturan Integrasi

Hubungkan ke Google Sheet via Apps Script (kode ada di file Code.gs)
Jam cut-off laporan finance (per hari)
Satu periode = cut-off hari sebelumnya s/d cut-off hari ini. Contoh: periode hari Sabtu = Jumat 17:00 s/d Sabtu 14:30. Spend diinput dari 3 angka Ads Manager: (24 jam kemarin − kemarin s/d cut-off) + hari ini s/d cut-off; top up yang jamnya lewat cut-off otomatis dihitung ke periode (tanggal) berikutnya.
Belum ada sinkronisasi.
Cara pasang: buka Google Sheet → Extensions → Apps Script → hapus isi lama, tempel kode di bawah → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → salin URL /exec ke kolom di atas.
Sheet dibuat otomatis saat pertama dipakai: Master (agensi & akun), TopUpAgensi, TopUpAkun, SpendAkun, SaldoAwal. Jika sebelumnya memakai sheet Agensi & Akun, datanya disalin otomatis ke Master saat pertama kali dipakai (sheet lama boleh dihapus setelah itu). Setelah kode diperbarui, deploy ulang lewat Manage deployments → Edit → New version.
